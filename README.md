# Sailfish Account NextCloud

The Nextcloud account consists of a variety of components
- Accounts & SSO plugin files (.provider/.service)
- Settings Accounts ui plugin files (.qml)
- Gallery application plugin to display Nextcloud content
- EventsView extension plugin to display Nextcloud notifications
- Buteo sync plugins specific to Nextcloud
  - gallery image downsync
  - backups upsync + downsync
  - event feed posts/notifications downsync
- Transfer engine sharing plugin

## Issue reporting

Please report issues to [Issue Tracker](https://github.com/sailfishos/issue-tracker/issues) repository and
label issues with nextcloud. You can also filter by [label](https://github.com/sailfishos/issue-tracker/issues?q=state%3Aopen%20label%3Anextcloud).

Worth noting that GitHub Issues provides a bug report template when creating a new issue.

Find more information from [Issue Tracker](https://github.com/sailfishos/issue-tracker).
